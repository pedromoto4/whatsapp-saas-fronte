# Screenshots de Onboarding

Coloque aqui os screenshots necessários para o wizard de onboarding:

## Arquivos Necessários

1. **business-manager-setup.png** - Tela de criação do Meta Business Manager
   - Dimensões recomendadas: 800-1200px de largura
   - Formato: PNG (melhor qualidade)
   - O que mostrar: Formulário de criação com campos destacados

2. **waba-creation.png** - Tela de criação da WhatsApp Business Account
   - Dimensões recomendadas: 800-1200px de largura
   - Formato: PNG
   - O que mostrar: Menu de configurações → Contas → WhatsApp → Botão "Adicionar"

3. **phone-verification.png** - Tela de verificação de número de telefone
   - Dimensões recomendadas: 800-1200px de largura
   - Formato: PNG
   - O que mostrar: Formulário de verificação com opções SMS/Chamada

## Como Capturar

Veja o guia completo em: `GUIA-SCREENSHOTS.md` na raiz do projeto

## Dicas

- Use setas vermelhas para indicar onde clicar
- Blur informações sensíveis (emails, números, etc.)
- Mantenha consistência visual entre os screenshots
- Use modo claro do navegador para melhor visualização
